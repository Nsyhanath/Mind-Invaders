Mind Invaders Changelist
I originally had the level design to be three stages but I decided to change to one big final boss since I had thought the game should be more direct and wanted it to be a mini-game. I had also changed the sliding mechanic a little bit. It functions the same but I adjusted the speed and how long it lasts so that it can be a fun way for the player to have fun with the movement. Another thing was figuring out how much the boss fight difficulty should be and I had decided to have a second phase of the boss fight of when it drops to below 50 percent hp it would trigger the second phase where the fire rate would increase as well as there being a bullet spread.
